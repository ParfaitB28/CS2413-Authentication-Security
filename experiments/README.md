
# Security Experiments

This directory contains the controlled experiments used to evaluate the authentication security mechanisms.

## Online Experiments
- Brute-force login testing
- Dictionary attacks
- Credential-stuffing experiments
- Rate-limiting and account-lockout evaluation
- Multi-factor authentication effectiveness

## Offline Experiments
- Password hash cracking comparisons
- Salt effectiveness
- Password hashing performance

## Evaluation
Experiments compare Build A (baseline) with Build B (hardened).

Results will include attack success rates, attempts per minute, password cracking performance, and before-and-after evidence.

All experiments must run in a controlled local environment using synthetic test accounts only.
