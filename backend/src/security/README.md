
# Security Modules

This directory contains the security mechanisms implemented for the hardened authentication system (Build B).

## Components

- passwords/ - Password hashing, salting, and password-strength validation.
- rate-limit/ - Rate limiting, account lockout, and exponential backoff.
- mfa/ - Time-based One-Time Password (TOTP) multi-factor authentication.

Each component will be developed on its assigned feature branch and integrated into the core authentication system.
